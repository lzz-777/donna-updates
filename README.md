# Donna para Windows

[Baixar Donna 1.4.50](https://github.com/lzz-777/donna-updates/releases/download/v1.4.50/Donna-Setup-v1.4.50.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão entrega os ajustes aprovados de resposta do Discord quando a nuvem está indisponível e de isolamento de credenciais nos testes. Inclui os ajustes de emoções, pedidos ao Hermes e filtro de legendas da versão anterior. Mantém a transcrição padrão pela Groq whisper-large-v3-turbo, com fala inteira em português e reserva local. Não houve mudanças funcionais na etapa de compilação/publicação.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a versão.
