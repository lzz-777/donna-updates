# Donna para Windows

[Baixar Donna 1.4.49](https://github.com/lzz-777/donna-updates/releases/download/v1.4.49/Donna-Setup-v1.4.49.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão entrega os ajustes aprovados de reações emocionais, pedidos curtos ao Hermes, conversa por tarefa e filtro de legendas na transcrição. Mantém a transcrição padrão pela Groq whisper-large-v3-turbo, com fala inteira em português e reserva local. Nenhuma mudança funcional foi feita durante a compilação/publicação.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a versão.
