# Donna para Windows

[Baixar Donna 1.4.48](https://github.com/lzz-777/donna-updates/releases/download/v1.4.48/Donna-Setup-v1.4.48.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão entrega o código previamente aprovado: transcrição do modo auto igual ao Hermes, pela Groq whisper-large-v3-turbo, com fala inteira em português e reserva local. Mantém os ajustes aprovados de interrupção, despertar e histórico, sem mudanças funcionais durante a compilação/publicação.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a versão.
