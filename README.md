# Donna para Windows

[Baixar Donna 1.4.53](https://github.com/lzz-777/donna-updates/releases/download/v1.4.53/Donna-Setup-v1.4.53.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão corrige a disputa entre a Donna e o Hermes Desktop ao acompanhar uma conversa em execução. Ambos usam a mesma autoridade residente, mantendo o histórico e as proteções contra execução duplicada.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
