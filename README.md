# Donna para Windows

[Baixar Donna 1.4.41](https://github.com/lzz-777/donna-updates/releases/download/v1.4.41/Donna-Setup-v1.4.41.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão melhora a recuperação de entregas após reinício, o transporte privado de arquivos entre PCs atualizados e a identificação de ações sem comprovação. Inclui diagnóstico do modelo e das etapas de áudio realmente utilizadas, mantendo o visual escuro e o zoom da versão anterior.

Instale ou atualize nos dois computadores para usar os arquivos remotos. Contas e serviços externos dependem da sua autorização. Chaves, memórias e configurações pessoais não são distribuídas neste instalador.
