# Donna para Windows

[Baixar Donna 1.4.61](https://github.com/lzz-777/donna-updates/releases/download/v1.4.61/Donna-Setup-v1.4.61.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão traz o ajuste de volume do computador feito na hora pela própria Donna, recuperação mais rápida quando o modelo principal de IA trava e uma voz neural online com mais paciência antes de cair na voz local.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
