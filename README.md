# Donna para Windows

[Baixar Donna 1.4.60](https://github.com/lzz-777/donna-updates/releases/download/v1.4.60/Donna-Setup-v1.4.60.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão traz mais jeitos de pedir o modo de espera sem ativar por engano, geração de imagens pelo 9Router com botão "Baixar imagem" e janela "Salvar como", voz que não trava quando a voz online demora, resposta falada também para mensagens digitadas e o modo opcional "assistente" no perfil Donna-Hermes.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
