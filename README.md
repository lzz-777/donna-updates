# Donna para Windows

[Baixar Donna 1.4.52](https://github.com/lzz-777/donna-updates/releases/download/v1.4.52/Donna-Setup-v1.4.52.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão retoma a conversa do Hermes no mesmo contexto e corrige a preparação de prints e arquivos solicitados por outro computador pareado. O destino executa localmente e a Donna devolve o resultado pelo canal de origem, sem repetir a tarefa ao tentar entregar novamente.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a versão.
