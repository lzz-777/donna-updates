# Donna para Windows

[Baixar Donna 1.4.44](https://github.com/lzz-777/donna-updates/releases/download/v1.4.44/Donna-Setup-v1.4.44.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão elimina a carga de Whisper e da prévia local no modo API, usa CPU na reserva automática e pausa a animação sem foco. Inclui registro local limitado de consumo, ajustes no cancelamento de eco, recuperação de conclusões e reaproveitamento da confirmação em pedidos em segundo plano. A qualidade acústica precisa ser validada no equipamento utilizado.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber as correções.
