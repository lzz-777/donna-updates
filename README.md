# Donna para Windows

[Baixar Donna 1.4.45](https://github.com/lzz-777/donna-updates/releases/download/v1.4.45/Donna-Setup-v1.4.45.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão evita iniciar e pré-carregar o Headroom quando a conexão ativa não precisa dele. Preserva sua instalação e configurações, além dos ajustes de voz por API, interrupção e recursos da 1.4.44. A melhora de FPS precisa ser conferida no equipamento do jogo.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber as correções.
