# Donna para Windows

## [⬇️ Baixar Donna-Setup-v1.4.40.exe](https://github.com/lzz-777/donna-updates/releases/download/v1.4.40/Donna-Setup-v1.4.40.exe)

Baixe somente o instalador acima. Ele instala ou atualiza a Donna preservando as configurações existentes.

### Novidades da 1.4.40

- Rotinas respeitam o computador indicado no pedido atual, mesmo quando o destino salvo é outro. Um PC indisponível não provoca execução na máquina local.
- Entrega de resultados e fotos de tarefas em segundo plano preserva o solicitante e o canal, sem esperar uma nova mensagem. Inclui novas tentativas após falha e conclusão de uma tarefa quando o principal do Discord mudou.
- Registros técnicos de fila, falha e envio ajudam a diagnosticar entregas sem armazenar conversas, fotos ou credenciais.
- Visual sempre escuro e zoom disponível também no modo gráfico de reserva.

As chaves e contas são configuradas por cada usuário; o instalador não inclui dados pessoais nem credenciais do desenvolvedor.

Os arquivos Donna-win64.zip e Donna-win64.zip.sha256 são usados pelo atualizador automático. Não é necessário baixá-los manualmente.
