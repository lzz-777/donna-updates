# Donna para Windows

[Baixar Donna 1.4.56](https://github.com/lzz-777/donna-updates/releases/download/v1.4.56/Donna-Setup-v1.4.56.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão traz a escolha do chat do Hermes por voz ("quais chats", "usa o chat ...", "novo chat"), aviso claro quando o chat está em uso, primeira frase falada assim que o Hermes a escreve, imagens e arquivos entregues pelo Hermes na tela e no mesmo canal, e um aviso de espera que não cancela o pedido em andamento.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
