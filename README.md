# Donna para Windows

[Baixar Donna 1.4.46](https://github.com/lzz-777/donna-updates/releases/download/v1.4.46/Donna-Setup-v1.4.46.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão corrige a abertura da aba Voz e microfone, que podia mostrar `note is not defined`. Mantém as melhorias de recursos, voz por API e Headroom da 1.4.45, sem mudar configurações de áudio ou personalidade.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a correção.
