# Donna para Windows

[Baixar Donna 1.4.68](https://github.com/lzz-777/donna-updates/releases/download/v1.4.68/Donna-Setup-v1.4.68.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão abre o Redid Elo como roteador (sem voltar ao 9Router), mantém a conexão entre os PCs mesmo quando a rede falha na hora de renovar a sessão e, se a conexão for perdida, explica como reconectar com um código.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
