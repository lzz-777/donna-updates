# Donna para Windows

[Baixar Donna 1.4.51](https://github.com/lzz-777/donna-updates/releases/download/v1.4.51/Donna-Setup-v1.4.51.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão corrige a entrega automática de resultados no Discord quando a nuvem falha ou outro PC passa a receber os novos pedidos. Também permite confirmar por senha o pedido que continua na Donna original após essa troca. A senha, o usuário, o canal, a validade e a identificação do pedido continuam sendo verificados. Erros do formulário aparecem de forma privada, sem uma mensagem falsa de confirmação concluída.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a versão.
