# Donna para Windows

[Baixar Donna 1.4.54](https://github.com/lzz-777/donna-updates/releases/download/v1.4.54/Donna-Setup-v1.4.54.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão corrige o erro `invalid_params` na criação de conversas do Hermes com títulos longos. O pedido completo é preservado; somente o título se adapta ao limite aceito pelo Hermes.

Mantidas as proteções e o uso do servidor compartilhado para acompanhar tarefas no Hermes Desktop.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
