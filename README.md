# Donna para Windows

[Baixar Donna 1.4.67](https://github.com/lzz-777/donna-updates/releases/download/v1.4.67/Donna-Setup-v1.4.67.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão traz a seção "9Router — imagem e voz reserva" nas Configurações, com campos para o endereço e a chave do 9Router de cada PC, o modelo de imagem, a voz reserva e um botão que testa tudo de verdade.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos no instalador. Atualize cada computador quando desejar receber a correção.
