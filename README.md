# Donna para Windows

[Baixar Donna 1.4.47](https://github.com/lzz-777/donna-updates/releases/download/v1.4.47/Donna-Setup-v1.4.47.exe)

Assistente pessoal com voz, texto, memória, rotinas e integração com Hermes e Discord.

Esta versão corrige falhas no encaminhamento de interrupções do modo live e evita recuperação local prematura da transcrição por API. Mostra o motivo das falhas de API e a disponibilidade do cancelamento de eco no diagnóstico. Testes automatizados não substituem a calibração e validação acústica em cada computador.

Chaves, memórias, nomes de dispositivos e configurações pessoais não são distribuídos neste instalador. Atualize cada computador para receber a correção.
